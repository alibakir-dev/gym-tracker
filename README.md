# PulseLog — Gamified Gym & Adaptive TDEE Tracker

Full-stack workout logger, muscle balance analyzer, and 14-day adaptive TDEE tracker built with the **PulseLog Kinetic Mono** design system (`Roboto Mono`).

## Tech Stack
- **Frontend:** TypeScript (`strict`), React (Vite), React Router, Tailwind CSS, TanStack Query, React Hook Form + Zod, Zustand
- **Backend:** Node.js, Express, PostgreSQL (Neon), Drizzle ORM, Session Auth (`HttpOnly` cookie + `argon2`)
- **Testing:** Vitest, React Testing Library, Supertest
